Om projektet

Syftet med denna applikation är att praktisera moderna metoder för autentisering och dataskydd. Genom att bygga ett eget API har jag fått djupare förståelse för hur man skyddar användardata och begränsar åtkomst till känsliga resurser.

    Teknisk stack

  • Backend: Express med fokus på RESTful design.
  • Lösenordssäkerhet: Användning av bcrypt för envägs-hashing av lösenord innan de lagras i databasen.
  • Autentisering: Implementering av JSON Web Tokens (JWT) för att hantera säkra sessioner och verifiera användarens identitet vid anrop till skyddade endpoints.
  • Frontend: Byggd för att demonstrera hur token-baserad inloggning fungerar i praktiken.
